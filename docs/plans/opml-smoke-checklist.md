# OPML 导入导出 · 手动冒烟测试清单

每次发布前在真机（Android 优先）过一遍。预计 10 分钟。

## 准备

- [ ] App 已登录本地模式，有 ≥3 个订阅、≥20 篇文章
- [ ] 手机连接 Mac，`adb logcat -s flutter` 开着

## 导出

- [ ] 设置 → OPML 导入与导出 → 导出 OPML
- [ ] 系统分享/保存成功，无异常日志
- [ ] 打开导出的 OPML 文件：包含全部订阅（xmlUrl 与订阅页一致）
- [ ] 分组信息存在（`<outline text="分组名">` 包裹层级）
- [ ] 播客订阅（有 enclosure 的）也在导出内

## 导入

- [ ] 用导出的 OPML（或本仓库测试 OPML）执行导入
- [ ] 导入完成提示成功，订阅数增加且与文件一致
- [ ] 重复导入同一文件：订阅不重复（URL 去重生效）
- [ ] 导入含非法条目的 OPML（随便一行垃圾 XML）：
      - [ ] 不崩溃，给出明确错误提示
      - [ ] 合法条目仍然被导入
- [ ] 导入空 body 的 OPML：提示成功但 0 个订阅，无崩溃
- [ ] 导入后收件箱能正常下拉刷新出新订阅的文章

## 边界

- [ ] OPML 内含中文分组名/中文标题：显示正常
- [ ] OPML 内 xmlUrl 为 http（非 https）：能导入且刷新按 http 处理
- [ ] 100+ 条目的大文件导入：10 秒内完成，UI 不卡死

## 回归

- [ ] 导入/导出后，AI 设置（API Key、自动翻译开关）不受影响
- [ ] 收藏、已读状态不受导入影响

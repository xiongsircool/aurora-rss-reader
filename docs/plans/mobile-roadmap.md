# Aurora 移动端路线图

> 状态:进行中 · 更新于 2026-09-05
> 分支:`feature/mobile-flutter-v1`
> 已发布:桌面端 v0.2.0;移动端为开发预览(未上架)

## 已完成 ✅

### 基础引擎
- [x] RSS 1.0 (RDF) / RSS 2.0 / Atom / Media RSS / Podcast 解析
- [x] 字符编码:UTF-8、UTF-16LE/BE、GBK、Big5、Shift-JIS(GB18030 四字节为已知缺口)
- [x] HTTP:原始字节、gzip/deflate、重定向、超时、体积限制、环境代理、显式代理
- [x] Drift/SQLite schema v1→v3 迁移(带真实快照迁移测试)
- [x] FTS5 全文搜索(含提取正文)、游标分页、feed+guid 去重、级联删除
- [x] 50,000 篇 SQLite 性能基准(主机 1111ms 写入/9.4ms 首页)
- [x] 26 个真实 Feed 兼容报告;依赖许可证 GPLv3 审计

### 产品功能
- [x] 四标签壳层:收件箱/收藏/订阅/设置
- [x] 订阅:添加、单源刷新、全量刷新、删除(级联清理)
- [x] 分组:订阅页分组展示(折叠/未读数)、添加时选分组、移动/重命名/解散分组、收件箱分组筛选(显示/屏蔽模式)
- [x] 收件箱:全部/未读筛选、加载更多、下拉刷新
- [x] 已读/未读、收藏/取消(持久化)
- [x] 全部标为已读
- [x] 深色模式(跟随系统)
- [x] 文章阅读页:净化 HTML 渲染、自动标读、外链系统浏览器打开
- [x] 网页全文提取:Mozilla Readability + 失败回退 + 缓存
- [x] 内容切换:网页全文 / 订阅原文(SegmentedButton)
- [x] 图片防盗链 Referer 支持(阅读页 + 收件箱缩略图)
- [x] 图片点击放大(全屏/缩放/双击放大)
- [x] 图片磁盘缓存(cached_network_image)
- [x] 阅读字号调节(14-22,持久化)
- [x] 收件箱摘要显示(HTML 去标签)
- [x] 本地搜索页(FTS5)
- [x] HTTP 代理持久化设置
- [x] OPML 导入(嵌套分组/去重)/导出(系统分享)
- [x] 筛选浮窗(全部/仅未读 + 分组显示开关)

### AI 能力
- [x] AI 设置页:分页式(连接/参数/策略),多参数支持
- [x] API Key 安全存储(iOS Keychain / Android Keystore)
- [x] AI 配置:端点/模型/Key/Max Tokens/Context Window/Temperature/超时/重试/语言/推理
- [x] 单篇摘要:OpenAI 兼容流式输出 + 阅读页面板
- [x] 摘要按 entry+language 缓存
- [x] 标题翻译(手动触发 + 缓存)
- [x] 请求超时 + 自动重试(429/5xx)
- [x] AI 失败不影响正文与阅读状态

### 质量与基础设施
- [x] 62 项确定性测试全绿;`flutter analyze` 零问题
- [x] Android 16 真机(小米 14 Pro)全流程验证;Impeller 兼容修复
- [x] Android/iOS 模拟器集成测试(导航 + SQLite 文件库)
- [x] 真实网络设备测试(Android/iOS 模拟器)
